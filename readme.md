# Talal Nayer portfolio

Reference site: https://www.talalnayer.com/home

This repository now contains a static rebuild of that portfolio for GitHub Pages.

## Local preview

Run a simple static server from the repository root, for example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

A workflow is included at [.github/workflows/deploy-pages.yml](/Users/abubaker/dev/talaal_website.worktrees/mimic-artist-portfolio-github-pages/.github/workflows/deploy-pages.yml) to deploy the site on pushes to `main`.
